🌐 Proyecto Next.js - Soap Ayuda  
Este proyecto es una aplicación web desarrollada con Next.js 14, React 18, TailwindCSS, DaisyUI y styled-components.  
Está pensado para ayudar a instituciones y fundaciones mediante la venta online del seguro obligatorio automotriz.  
Incluye integración con animaciones AOS y Google Analytics para seguimiento.

---

🚀 Tecnologías utilizadas  
⚡ Next.js 14 - Framework de React con renderizado híbrido (SSR/SSG).  
⚛️ React 18 - Biblioteca para construir interfaces de usuario.  
🎨 TailwindCSS - Framework CSS para estilos utilitarios.  
🌼 DaisyUI - Librería de componentes para TailwindCSS.  
💅 styled-components - CSS-in-JS para estilos dinámicos.  
🎞️ AOS - Animaciones on scroll.  
📊 Google Analytics - Integrado mediante scripts en el layout.  
☁️ Netlify (opcional) - Plataforma recomendada para despliegue.

---

⚙️ Instalación  
-- npm install

🚀 Ejecutar en modo desarrollo
-- npm run dev
